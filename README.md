 Campus Fault Reporting System

A web application designed for students and staff to log campus facility issues (plumbing, electrical, etc.) 
 Key Features
- Dynamic Input Display
- Real-Time Live Preview
- Client-Side Validation

 
- Frontend: HTML5, CSS, JavaScript 
- Backend: PHP, MySQL

 Local Setup
1. Clone the repository to your local web server directory 
2. Open `index.html` in your browser or run through Apache.
